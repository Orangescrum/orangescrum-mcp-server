# Action item patterns

Phrases that usually signal a commitment worth turning into a task.

## Explicit ownership

- "<Name> will ..."
- "<Name> to ..." ("Sam to send the contract")
- "Action: <Name> ..."
- "AI: ..." or "TODO: ..."
- "@<Name> ..."

## Implied ownership

- "I'll take that" (owner: the speaker)
- "Can you ...?" followed by agreement (owner: the person asked)
- "Let's have <team> look into ..." (owner: the team lead, confirm with the user)

## Deadlines

| Phrase | Convert to |
| --- | --- |
| "by Friday" | the next Friday's date |
| "end of week" / "EOW" | this Friday |
| "next sprint" | leave the date empty and mention the sprint in the description |
| "before the release" | ask for the release date, or use `list_releases` to find it |
| "ASAP" | today plus two working days, priority `high` |

## Not action items

- Decisions with no follow-up ("We agreed to keep the current pricing")
- Status updates ("The API is done")
- Open questions with no owner (list these separately in the summary)
